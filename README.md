# TaskSorter 团队任务跟踪看板 📋⚡

为 5 人敏捷团队量身定制的**现代清爽风任务看板**。针对 Windows 电脑长期开启场景优化，局域网全员免登录快速协作，纯 JSON 本地免运维存储。

---

## ✨ 核心特性

1. **时效分类看板（4 个核心泳道）**：
   * ⚡ **短（这两天）**：聚焦 48 小时内的核心待办与紧急 Bug。
   * ⏱️ **中（一周）**：本周重点计划与冲刺事项。
   * 🗓️ **长（一个月）**：本月重点推进目标与里程碑。
   * 📦 **待办（几个月）**：长期规划、构想与灵感池。

2. **极简免运维存储（纯 JSON）**：
   * 数据纯保存在单个 `data/db.json` 文件中，零数据库服务安装。
   * 系统每小时自动轮转备份至 `data/backups/`，页面顶部提供一键“备份 JSON”下载。

3. **实时多端同步（WebSocket 双向驱动）**：
   * 团队 5 人中任意一人拖动卡片、新增待办或打勾完成，其他人的浏览器屏幕**毫秒级无感更新**，无需手动刷新。

4. **视觉与交互质感**：
   * **清爽审美**：柔和微色调泳道、圆角浮层、微动效与毛玻璃质感。
   * **极度顺滑的拖拽**：基于 `@hello-pangea/dnd` 物理反馈，支持同列快速重排与跨列流转。
   * **任务细节齐备**：P0~P3 优先级标签、多人员分配、子清单 Checklist 进度微条、到期智能倒计时（今天到期/超期高亮）、任务完成撒花反馈（Confetti）。
   * **明亮 / 暗色模式**：右上角一键切换，偏好自动保存。

5. **5 人专属快速过滤与修改**：
   * 顶部常驻团队 5 位成员的专属代表色头像，点击任意头像即可秒级筛选该成员负责的任务。
   * 支持在“成员设置”中直接自定义团队 5 人的真实姓名、岗位角色与代表色。

6. **全局快捷键**：
   * `N`：快速打开新建任务窗口。
   * `/`：快速聚焦全局搜索栏。
   * `Ctrl + Enter`：在任务弹窗中快速保存。
   * `Esc`：关闭弹窗。

## 🚀 部署到 Windows 电脑（长期运行）

### 方法一：双击一键启动（最推荐）
1. 将本项目文件夹（`task-sorter`）拷贝到目标 Windows 电脑上。
2. 确保电脑已安装 Node.js（推荐 LTS 版本：https://nodejs.org）。
3. 直接双击运行项目根目录下的 **`start.bat`**。
4. 命令行窗口会显示类似如下日志：
   ```
   🚀 TaskSorter 团队任务跟踪服务已就绪！
   📡 本机访问:   http://localhost:3000
   🌐 局域网访问 (供团队其他成员电脑访问):
      ➜ http://192.168.1.105:3000
   ```
5. 团队其他成员在各自电脑/手机浏览器中打开该局域网网址（例如 `http://192.168.1.105:3000`）即可使用！

### 开机自启（一键安装）
想让 Windows 开机后自动在 80 端口启动服务（无窗口后台运行）：
1. 在项目根目录双击运行 **`start.bat`** 可正常启动服务（或直接运行下面第 2 步安装自启）。
2. 执行一次安装命令：
   ```
   start.bat install
   ```
   脚本会在“启动”文件夹中创建隐藏启动器，下次开机后 TaskSorter 自动运行在 80 端口。
3. 如需移除开机自启：
   ```
   start.bat uninstall
   ```
